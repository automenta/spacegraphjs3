SpaceGraphJS Comprehensive Demo

This demo showcases all implemented features:

  • All layout engines
  • All element actors
  • Edge interaction system
  • Camera controls
  • HUD with REPL console

Interaction Guide

  • Hover/Ctrl+Click nodes/edges
  • Drag nodes to reposition
  • Drag background to pan
  • Scroll to zoom
  • Arrow keys for navigation
  • WASD for panning
  • +/- for zooming
  • REPL Console in HUD for commands
