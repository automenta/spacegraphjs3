HTML Node Demo

This demo showcases rich interactive HTML nodes in 3D space with:

  • Interactive forms and controls
  • Dynamic styling and animations
  • Real-time data visualization
  • Draggable and resizable nodes

Node interactions:

Click and drag to rotate view
Scroll to zoom in/out

Interaction Guide

  • Click on HTML nodes to interact with controls
  • Drag nodes to reposition them in 3D space
  • Hover over nodes to see visual feedback
  • Use form controls to update node data
  • Click "Add New Node" to create more nodes
