🚀 SpaceGraph - Simplified Getting Started API

Create beautiful 3D graph visualizations with just a few lines of code!

✨ Auto-Setup

Automatic BVH acceleration, default plugins, and smart defaults - just provide your data!

🎯 Smart Layouts

Auto-selects the best layout based on your data size, or specify your preference.

📷 Zero-Config Camera

Intelligent camera positioning that frames your data perfectly.

🎨 Default Styling

Beautiful default color schemes and hover effects out of the box.

Simple Graph Demo

This demonstrates creating a basic graph with just nodes and edges.

// Create a simple graph with automatic setup const graph = SpaceGraph.create({ nodes: [ { id: '1', type: 'sphere', label: 'Node 1', position: { x: 0, y: 0, z: 0 } }, { id: '2', type: 'sphere', label: 'Node 2', position: { x: 10, y: 0, z: 0 } }, { id: '3', type: 'sphere', label: 'Node 3', position: { x: 5, y: 10, z: 0 } }, ], edges: [ { id: 'e1', source: '1', target: '2', color: '#ff6b6b' }, { id: 'e2', source: '2', target: '3', color: '#4ecdc4' }, { id: 'e3', source: '3', target: '1', color: '#45b7d1' }, ], container: '#simple-graph', });

Large Graph Demo

This shows how the API automatically handles larger datasets with appropriate optimizations.

// Large graph with 100 nodes automatically uses grid layout and basic renderer const largeGraph = SpaceGraph.create({ nodes: Array.from({ length: 100 }, (_, i) => ({ id: `node-${i}`, type: 'sphere', label: `Node ${i}`, })), edges: Array.from({ length: 150 }, (_, i) => ({ id: `edge-${i}`, source: `node-${Math.floor(Math.random() * 100)}`, target: `node-${(Math.floor(Math.random() * 100) + 1) % 100}`, })), layout: 'grid', // Explicitly choose grid for large datasets useBasicRenderer: true, // Better performance for large graphs container: '#large-graph', });

Custom Styling Demo

Override default styles while still benefiting from auto-setup.

// Custom styling with auto-setup const customGraph = SpaceGraph.create({ nodes: [ { id: 'a', type: 'sphere', label: 'A' }, { id: 'b', type: 'sphere', label: 'B' }, { id: 'c', type: 'sphere', label: 'C' }, ], edges: [ { id: 'ab', source: 'a', target: 'b' }, { id: 'bc', source: 'b', target: 'c' }, { id: 'ca', source: 'c', target: 'a' }, ], style: { 'node:hover': { color: '#ff0000', glow: { color: '#ff0000', strength: 1.0 }, }, 'edge:selected': { color: '#00ff00', width: 5, }, }, camera: { distance: 30, }, container: '#custom-graph', });
